## 🎯 **GUIDE: How to Generate Each Feature in Figma Make**

### **STEP-BY-STEP PROMPT STRATEGY**

Figma Make works best with **one screen per prompt**. Don't paste all 100 screens at once. Here's how to generate them: [linkedin](https://www.linkedin.com/posts/think-in-system_figma-make-prompting-best-practices-think-activity-7427588647312355328-Qt4e)

***

### **PHASE 1: Generate Customer Screens (53 screens)**

#### **PROMPT 1: Welcome/Login Screen**
```
Build screen 1.1: Welcome/Login Screen for Kuula app

Task: Create login entry point for new and existing users

Elements:
- App logo at top center (circular icon with shield + coin)
- "Kuula" text below logo (large, bold)
- Small text: "Fast, secure loans via mobile money"
- Two fullscreen buttons: "Create Account" (primary blue #2563EB) and "Log In" (secondary, gray border)
- "Continue with National ID" button below (primary, blue)
- Optional: "Continue with Google" button (gray)

Behavior:
- "Create Account" button navigates to Create Account screen
- "Log In" button enables password input
- "Continue with National ID" navigates to KYC Verification screen

Constraints:
- iPhone 15 Pro frame (393x851)
- 16px padding, 48px button height
- White background, blue primary color
Don't change anything else.
```

***

## 🎨 **DESIGN SYSTEM TO APPLY FIRST**

Before generating screens, create a **design system** in Figma:

```
Build Kuula Design System:

Task: Create reusable components and styles

Elements:
- Color Palette:
  - Primary Blue: #2563EB
  - Success Green: #10B981
  - Error Red: #EF4444
  - Background White: #FFFFFF
  - Text Dark: #1F2937
  - Text Gray: #6B7280
  
- Typography:
  - Heading Large: 28px, bold
  - Heading Medium: 22px, bold
  - Heading Small: 18px, medium
  - Body: 16px, regular
  - Small: 14px, regular

- Components:
  - Button Primary: 48px height, blue background, white text
  - Button Secondary: 48px height, white background, blue border
  - Card: White background, 8px border radius, subtle shadow
  - Input Field: 48px height, border gray, padding 16px
  - Badge: Small rounded pill, green/blue/red based on status

Constraints:
- Consistent spacing: 16px padding, 24px between elements
- Use SF Pro font (iOS system font)
Don't change anything else.
```

## 📋 **CHECKLIST: Verify Each Screen After Generation**

After Figma generates each screen, check:

✅ **1. Correct frame size** (iPhone 15 Pro for customer, Desktop for admin)  
✅ **2. All elements present** (buttons, inputs, text as specified)  
✅ **3. Colors match** (blue #2563EB, green #10B981)  
✅ **4. Spacing correct** (16px padding, 24px between cards)  
✅ **5. Buttons clickable** (navigation links set up)  
✅ **6. No mock data** (placeholders, not real numbers/names)  

**If something is wrong**, use this revision prompt:

```
Fix: [What's wrong]

Change: [Specific fix needed]
- Example: "Change button color to blue #2563EB"
- Example: "Add 16px padding to all sides"
- Example: "Make 'Apply Now' button 50% width"

Maintain: All other design elements unchanged
Don't change anything else about the design.
```
